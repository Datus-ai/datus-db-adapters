# datus-hologres

Hologres database adapter for [Datus](https://github.com/Datus-ai/datus-agent).

## Overview

Hologres is PostgreSQL-compatible. This adapter skeleton registers a dedicated
`hologres` adapter type while reusing the existing PostgreSQL connector behavior
for SQLAlchemy connection handling, query execution, metadata discovery, and
identifier behavior.

## Installation

```bash
pip install datus-hologres
```

## Usage

Configure Hologres with the `hologres` type:

```yaml
namespace:
  hologres_prod:
    type: hologres
    host: <hologres-host>
    port: 80
    username: <username-or-accesskeyid>
    password: <password-or-accesskeysecret>
    database: <database>
    schema: public
    sslmode: prefer
```

Supply required authentication values through your normal Datus configuration or
secret handling.

Or use it programmatically after constructing the config from your runtime
configuration source:

```python
from datus_hologres import HologresConfig, HologresConnector

config = HologresConfig(**runtime_config)
connector = HologresConnector(config)
```

## Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `host` | str | `"127.0.0.1"` | Hologres instance host |
| `port` | int | `80` | Hologres PostgreSQL-compatible port |
| `username` | str | required | Hologres username or AccessKeyID |
| `password` | str | `""` | Hologres password or AccessKeySecret |
| `database` | str | `None` | Default Hologres database name |
| `schema_name` / `schema` | str | `"public"` | Default Hologres schema name |
| `sslmode` | str | `"prefer"` | PostgreSQL-compatible SSL mode |
| `timeout_seconds` | int | `30` | Connection timeout in seconds |

## Manual Validation (Optional)

These read-only checks can be run manually from any SQL client already connected
to a Hologres database. They are not CI requirements, and the adapter does not
require a live Hologres service for unit tests.

```sql
SELECT 1 AS ok;
```

```sql
SELECT current_database() AS database_name, current_schema() AS schema_name;
```

```sql
SELECT
  table_schema,
  COUNT(*) AS table_count
FROM information_schema.tables
WHERE table_schema NOT IN ('pg_catalog', 'information_schema')
GROUP BY table_schema
ORDER BY table_schema
LIMIT 50;
```

```sql
SELECT
  table_schema,
  table_name,
  table_type
FROM information_schema.tables
WHERE table_schema IN ('public', '<schema_name>')
ORDER BY table_schema, table_name
LIMIT 50;
```

The external table check requires an already-attached external or foreign schema
in Hologres; replace `<external_schema>` and `<external_table>` with names
configured in your instance.

```sql
SELECT *
FROM "<external_schema>"."<external_table>"
LIMIT 1;
```

## Current Limitations

- Hologres-specific DDL optimization is not yet implemented.
- Hologres-specific distribution, storage, and external table syntax is not
  validated or generated by this skeleton.

External tables are treated as normal SQL-accessible metadata for now.
